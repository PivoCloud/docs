# PivoCloud documentation

This repository holds the published source of [docs.pivocloud.com](https://docs.pivocloud.com).

Read the documentation at **[docs.pivocloud.com](https://docs.pivocloud.com)**. This repository
exists so that the documentation platform has something to build from, and so that anyone can read
the source of a page in plain markdown.

Everything here except this file and `MIRROR-NOTE.md` is generated. It is copied from the
`docs/customer/` directory of the PivoCloud monorepo and republished on every merge, which replaces
whatever was here before. Read `MIRROR-NOTE.md` before opening a pull request.

Found a problem in the documentation? Write to support@pivocloud.com.
