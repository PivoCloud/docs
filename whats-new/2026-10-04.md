## Two apps from one repository

If one GitHub repository holds more than one service, for example an API in one
folder and a web front end in another, each one can be its own app on PivoCloud.
Every entry below links to the page that explains it in full.

### October 2026

- Point two apps at the same repository and give each one its own `Root directory` and `Dockerfile path`, on the creation form or later on the app's settings page. Each app builds only its own folder and runs at its own address: [how do I deploy my app](/apps/deploy).
- Deploy a repository that has no `Dockerfile` at its root. Set the two fields to where the file really is, and the form shows you the resolved path as you type: [what does my repository need](/apps/deployment-contract).

New entries appear here when there is something new for you to use. There is no
schedule, so nothing on this page is waiting for a date.
