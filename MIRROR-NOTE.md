# This tree is generated. Changes made here are lost.

Every file in this repository, except this note and `README.md`, is copied from the `docs/customer/`
directory of the PivoCloud monorepo by an automated job. That job runs on every merge and overwrites
whatever is here. A commit pushed directly to this repository is erased by the next publish,
silently, with no conflict and no warning.

That is why issues are disabled: a fix has to land in the source repository to survive, and an inbox
nobody reads is worse than a closed door. Pull requests cannot be disabled on a public repository,
so this note is what answers them. A pull request opened here will be closed unmerged, and the
change will not reach the site.

## Reporting a documentation problem

Write to support@pivocloud.com. Name the page, quote the sentence that is wrong or missing, and say
what you expected to read instead. That reaches the people who can change the source, and the fix
appears here on the next publish.
